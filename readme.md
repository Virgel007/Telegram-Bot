

# Telegram Bot на основе ChatGPT

Этот Telegram бот использует сервис ChatGPT для ответов на вопросы и задачи. Бот имеет следующие функции:

*   Ответы на вопросы
*   Задачи квиза
*   Перевод текста
*   Поговорить с известной личностью

## Установка и запуск

1.  Установите необходимые библиотеки: `pip install -r requirements.txt`
2.  Создайте файл `.env` с токенами: `CHATGPT_TOKEN` и `TELEGRAM_TOKEN`
3.  Запустите бота: `python bot.py`

## Команды бота

*   `/start` - главное меню
*   `/random` - рандомный факт
*   `/gpt` - задать вопрос ChatGPT
*   `/talk` - поговорить с известной личностью
*   `/quiz` - пройти викторину
*   `/translate` - переводчик

## Разработка

Бот написан на Python с использованием библиотеки `python-telegram-bot` и `openai`. Код бота разделен на несколько файлов:

*   `bot.py` - основной файл бота
*   `gpt.py` - сервис для работы с ChatGPT
*   `util.py` - утилитарные функции для работы с Telegram
*   `common.py` - общие функции для работы с Telegram
